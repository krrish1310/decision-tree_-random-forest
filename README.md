# Task 5 - Decision Trees and Random Forests (AI & ML Internship)

This project demonstrates classification using Decision Trees and Random Forests on a Heart Disease dataset.

## 📊 Dataset
We used the Heart Disease dataset (`heart.csv.xls`), which contains various health indicators and a target column indicating presence of heart disease.

## 🛠 Tools Used
- Python
- Anaconda/Jupyter Notebook
- Scikit-learn
- Pandas, Matplotlib, Seaborn

## ✅ Task Objectives
- Train a Decision Tree classifier and visualize the tree.
- Analyze overfitting and control tree depth.
- Train a Random Forest classifier and compare accuracy.
- Interpret feature importances.
- Evaluate using cross-validation.

## 📈 Results
- Decision Tree Accuracy: ~ (varies by depth)
- Random Forest Accuracy: ~ (higher than decision tree)
- Best results observed with Random Forest and controlled depth.
